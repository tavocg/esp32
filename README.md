# ESP32

Entorno de desarrollo para ESP32-C3 con MicroPython y PlatformIO.

## Correr un programa

```sh
cd mp-hello-world

# Usa el primer puerto serial
# Opcionalmente agregar: PORT=/dev/ttyACM0
make run
```

## Instalar un programa

```sh
cd mp-hello-world
make install
```

## Desinstalar

```sh
cd mp-hello-world
make uninstall
```
